利用するAIモデルの候補を指定してください

API キーは画面を閉じると消えます。保存する場合は、手順6「設定の保存と復元」で「秘密情報も暗号化して保存」を選んでください。

費用を計算する場合は、100万トークンあたりの入力・出力単価を USD で入力します。公式 OpenAI 接続先の GPT-6 Luna と GPT-6.2 Sol には標準単価の初期値があります。

参照する資料や、RAGの候補を指定してください

資料を登録済みの、テキスト埋め込み機能付きインデックスを指定してください。

共通して利用するプロンプトの候補を指定してください

回答モデルに共通で渡す指示を入力します。A と B を入力すると、両方を比較します。

質問と模範解答のリストを指定してください

モデルや資料を切り替えて結果を比較しましょう

登録済みの全モデルと、利用できる資料・Pinecone 検索の有無を組み合わせて比較します。

実サービスでは質問・資料・認証情報を必要に応じて指定先に送信し、生成と採点に料金が発生します。サンプルは固定応答で、プロンプトの効果は実モデルで確認します。

回答時間は資料検索から回答生成まで。概算は回答生成と採点の LLM 料金を標準単価で計算します。検索料金やキャッシュ割引は含みません。単価や使用量が不明な条件は「算出不可」です。

設定の保存や、復元をしましょう

設定はダウンロード先に保存されます。資料ファイルと質問 CSV は次回も選択してください。
